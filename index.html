Scenario

In modern mobile applications, data breaches are a severe threat due to insecure coding practices. Our team developed a secure financial tracking Android application to demonstrate how common vulnerabilities can be exploited and subsequently mitigated.

Project: SecureWallet Pro

Problem Statement

Many financial mobile apps fail to sanitize user inputs and secure local data, leaving them vulnerable to attacks. This project addresses these flaws by implementing secure coding practices across authentication, data storage, and network communication.

View Project on GitHub

Case 1: Login Test

Live Code Vulnerability Implementation.

Reflection: We learned that client-side validation alone is insufficient. Implementing secure token-based authentication and server-side rate limiting drastically improved our login security against brute-force attacks.

View Code

Case 2: Insecure Local Storage

Live Code Vulnerability Implementation.

Reflection: Storing sensitive data in plain text is highly risky. We utilized EncryptedSharedPreferences to ensure user tokens and preferences remain securely encrypted on the device.

View Code

Case 3: Hardcoded API Keys

Live Code Vulnerability Implementation.

Reflection: Hardcoding keys in the source code exposes backend services to unauthorized access. We resolved this by migrating secrets to local.properties and using the Secrets Gradle Plugin.

View Code

Case 4: SQL Injection

Live Code Vulnerability Implementation.

Reflection: Concatenating strings for SQL queries creates severe injection risks. Using Room with parameterized queries automatically neutralized this vulnerability and protected our local database.

View Code

Reflection & Learning Journey

This project significantly deepened our understanding of mobile application security. We transitioned from merely making features work to proactively thinking like attackers to secure our code. Collaborating on these vulnerability solutions taught us that security must be integrated throughout the development lifecycle, not treated as an afterthought.
